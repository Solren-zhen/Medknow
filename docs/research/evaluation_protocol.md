# 多中心外部验证实验方案（评估协议 v1.0）

- 制定日期：2026-08-03
- 项目：跨中心外部验证下的肺炎胸片检测 — 不确定性引导分诊研究
- 对应代码：`experiments_multicenter/`（CheXpert 训练 → RSNA/VinDr 外部测试）

## 1. 研究目标

1. 在 CheXpert 上训练肺炎二分类模型，量化其跨中心外部泛化能力（RSNA、VinDr-CXR）；
2. 评估 MC Dropout 不确定性 + 温度缩放校准在外部数据上的可靠性；
3. 量化"不确定性引导分诊"策略的临床权衡：人工复核转诊率 × 敏感度 × 误诊率。

## 2. 数据与划分（患者级，杜绝泄漏）

| 数据集 | 用途 | 划分 | 标签口径 |
|---|---|---|---|
| CheXpert（斯坦福 22 万张） | 训练 + 内部验证 | 按 Patient 分组 85/15 随机划分，seed=42 | 肺炎二分类：1=阳性，-1=阴性，0=不确定→按 policy 处理（默认 ignore） |
| RSNA 肺炎检测（3 万张带框） | 外部测试 1 | 固定测试子集（患者级去重，1 人 1 图） | 有框=阳性；正常=阴性 |
| VinDr-CXR（1.8 万张） | 外部测试 2 | 全部（患者级去重） | pneumonia=1 阳性；全部发现为 0 阴性；pneumonia=2（不确定）剔除 |

细节：
- CheXpert 仅用 Frontal 正位片；
- 外部测试集的"患者级去重"（一人一图）作为默认，防止同一患者多图带来的相关性高估；
- 训练前冻结协议，不因结果好坏回头改划分。

## 3. 模型与训练

- 主模型：EfficientNet-B0（ImageNet 预训练，冻结骨干、解冻最后两层 + 分类头）
- 基线：ResNet18（同设置）
- 损失：交叉熵 + 类别权重（样本不平衡）；优化器 AdamW（lr=1e-4, wd=1e-5）
- 早停：监控内部验证 AUC（patience=5）；AMP 混合精度；seed=42
- 数据增强：随机水平翻转、旋转 ±10°、亮度抖动；评估无增强
- 输出：最优 checkpoint + 训练曲线 + history JSON

## 4. 指标清单（固定）

| 指标 | 说明 | 报告位置 |
|---|---|---|
| AUC（95% CI） | 自举 2000 次置信区间 | 内部 vs 外部 |
| 敏感度 @ 95% 特异度 | FDA 审批常用口径 | 内/外部 |
| 敏感度 / 特异度 @ Youden 阈值 | 常规报告 | 内/外部 |
| ECE（10 bins） | 校准误差，温度缩放前后对比 | 内/外部 |
| Brier 分数 | 概率质量综合 | 内/外部 |
| 漏诊率（1−敏感度） | 临床安全核心 | 外部 |
| 转诊率-敏感度权衡曲线 | 不确定性阈值扫描 | 外部 |

统计口径：
- 内部（CheXpert 验证集）AUC 与外部（RSNA/VinDr）AUC 分别报告 95% CI（自举）；
- 亚组报告（可选 v1.1）：性别、年龄组、机构。

## 5. 不确定性引导分诊协议（核心贡献）

1. MC Dropout 30 次采样 → 每个样本得到均值概率 + 不确定性（熵 / 方差）；
2. 阈值 τ 扫描：不确定性 > τ → 转人工复核；≤ τ → AI 自动筛查；
3. 输出曲线：τ 变化下（a）转诊率、（b）自动筛查子集的敏感度/特异度、（c）转诊子集的错误率；
4. 检验假设 H2：高不确定子集错误率显著高于低不确定子集（Mann-Whitney U 或按分位数 χ² 检验）；
5. 推荐操作点：自动筛查子集达到敏感度 ≥ 95% 时的最低转诊率。

## 6. 分析脚本

| 脚本 | 功能 |
|---|---|
| `convert_rsna_dicom.py` | RSNA DICOM → PNG + 索引 CSV |
| `train_chexpert.py` | CheXpert 训练（患者级划分，早停，AMP） |
| `evaluate_external.py` | RSNA/VinDr/CheXpert-val 评估 + 指标 JSON |
| `temperature_scaling.py` | 内部验证集拟合温度，输出 temp.json |
| `uncertainty_mc.py` | MC Dropout 推理 + 不确定性质量指标 |
| `triage_analysis.py` | 转诊率-敏感度权衡曲线 + 操作点 |
