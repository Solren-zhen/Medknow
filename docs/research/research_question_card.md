# 研究问题卡片（Research Question Card）

> 生成时间：2026-08-03
> 项目基础：`pneumonia_classifier`（PyTorch 多模型 + MC Dropout + Grad-CAM + 温度缩放）
> 目标：中文核心期刊论著（主线）+ 系统综述（保底），1–2 年内完成

## 1. 候选研究问题（主）

**在跨机构（跨中心）影像域偏移条件下，基于胸部 X 光的深度学习肺炎检测模型，其预测不确定性和校准性能（ECE）能否作为"转人工复核"的可靠信号——在保持高敏感度（不漏诊）的同时，显著降低误诊率并提升外部泛化的可靠性？**

聚焦版本（资源受限时的降级方案）：

> 以 CheXpert（斯坦福）为训练集、MIMIC-CXR / RSNA / VinDr-CXR 为外部测试集，评估 MC Dropout 不确定性阈值引导的分诊策略，能否在外中心数据上实现"高敏感度 + 可量化的人工复核转诊率"。

## 2. 假设（H1–H3）

- **H1（泛化衰减）**：跨中心时模型外部 AUC 显著下降（相对内部验证），且校准恶化（ECE 上升）比准确率下降更明显。
- **H2（可靠拒识）**：按 MC Dropout 不确定性从低到高分层，高不确定子集的错误率显著高于低不确定子集——即不确定性可以作为"不敢看"的信号。
- **H3（校准可迁移）**：温度缩放 + MC Dropout 组合在外部数据上仍能改善 ECE，且不确定性阈值与转诊率、漏诊率存在可量化的权衡曲线。

## 4. 缺失证据（需要补）

1. 公开多中心数据：CheXpert / MIMIC-CXR（需申请） / RSNA 肺炎检测 / VinDr-CXR / PadChest；
2. 跨中心外部验证的实验设计与结果（内部 vs 外部 AUC/ECE 对比）；
3. 不确定性阈值 → 转诊率 / 误诊率 / 漏诊率的权衡曲线；
4. 与中文核心期刊现有工作（多为单中心内部验证）的系统对比；
5. （如拿到医院数据）本地真实队列外部验证 + 与影像科医生阅片对比。

## 5. 支持标准（论文可发表的最低门槛）

- 外部测试集 AUC 报告 95% CI（DeLong 检验）；
- 校准指标 ECE（<0.05 为良好），内部 vs 外部对比；
- 高不确定子集与低不确定子集的错误率差异有统计学意义（如 DeLong / 卡方检验）；
- 至少 2 个外部中心数据集（一训多测）；
- 患者级划分，杜绝图片级泄漏。

## 6. 证伪标准

- 若不确定性阈值无法区分正确/错误预测（拒绝率与错误率无梯度），则 H2/H3 不成立；
- 若校准在外部数据上完全不可迁移（ECE 反而恶化），需改写故事（例如仅报告校准作为局限性）。
